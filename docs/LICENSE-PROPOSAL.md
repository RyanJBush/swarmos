terms let others use and adapt the code, including commercially, while retaining
copyright and license notices. It does not require downstream source disclosure.
Source: https://choosealicense.com/licenses/mit/

The repository is still private and no license grant has been applied. The owner
must approve the text below before it is moved to a root LICENSE file. Public
visibility is a separate decision. Dependencies retain their own licenses.
